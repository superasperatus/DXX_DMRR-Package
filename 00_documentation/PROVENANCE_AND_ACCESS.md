# Provenance, access, and reuse

## Included evidence

Archived response data from the study are included so that the analysis can be
repeated without new commercial inference or external downloads. The archive,
stimuli, and numerical references have the following sources:

| Package location | Supplied source | Role |
| --- | --- | --- |
| `02_output/raw/main` | `results_commercial/raw_*_commercial.csv` | Six original main-run attempt files. |
| `02_output/raw/prompt` | `results_commercial/robustness_prompt/raw_prompt_*.csv` | Six original wording-check attempt files. |
| `02_output/raw/temperature_original` | `results_commercial/robustness_temp/raw_temp10_*.csv` | Six original nominal-temperature-check attempt files. |
| `02_output/raw/temperature_v2` | `results_commercial/robustness_temp_v2/raw_temp*.csv` | Sixteen later temperature-arm files. |
| `01_collection/stimuli` | `source/pool_final_200.csv` and two fixed subsamples in `robustness/Local-model-check-scripts` | Stimulus text, original A/B randomization, and exact item membership. |
| `02_output/raw/notes` | Two original content-filter note CSVs | Historical missingness explanations. |
| `00_documentation/references` | Displayed commercial numerical cells of Tables 6 and 11 in the R1 manuscript | Post-computation comparisons, separate from observations. |

Copies are byte-identical to their source files. The generated
[input manifest](../02_output/input_manifest.json) records source paths, row counts,
sizes, response-coding convention, and SHA-256 hashes. Processing verifies all
41 input files before doing analysis. Package-relative path components avoid
dependence on the original directory layout.

The original main/prompt/temperature collection was in May 2026; temperature-v2
timestamps are in September 2026. Timestamp precision does not establish a
verified timezone, server-side model build, or complete request provenance.

Only original raw attempt files are included: previously cleaned snapshots and
combined v2 CSVs are omitted because they duplicate the evidence. Cleaning and
combination are instead regenerated by code.

## Reference manuscript and course context

The reference for the numerical comparisons is the R1 manuscript of
*One Trial Is Not Enough: Measuring Systematic Bias in LLMs Through Repeated
Prompting*, Adam Wasilewski, Agnes Helme-Guizon, and Nikola Kozuljevic,
*Information Processing & Management*, manuscript identifier
`IPM-D-26-04197R1`.

In that manuscript bundle, Table 6 is on PDF page 18 and Table 11 on page 26.
The comparisons in this package refer to that version, not a later publisher
version. The complete source materials for the supplementary analyses are not
included.

The title page mentions Harvard Dataverse DOI
[10.7910/DVN/QX0CN5](https://doi.org/10.7910/DVN/QX0CN5). That external deposit
was not downloaded or independently verified for this package. The processing
workflow uses the included archive rather than retrieving that deposit.

Package organization follows the principles in Milos Fisar's course handout,
*Replication and Reproducibility: Publication-Ready Replication Packages*:
separate raw inputs, derived data, code, and results; provide one processing
entry point; document variables and access; and make results traceable.

The manuscript and handout PDFs are not redistributed here.

## Third-party data and licenses

Stimuli are derived from BBQ, WinoBias, and DiscrimEval, as identified by the
pool and article. The supplied 200-item pool is treated as a fixed input, not a
reproducible reconstruction of upstream source sampling. Original benchmark
versions, complete screening annotations, and the initial candidate pool are
not included.

**No blanket open-data license is asserted, and a software license has not been
selected for this package.** Before redistributing or reusing the materials,
check:

1. Redistribution and attribution conditions for each upstream benchmark and
   adapted stimulus.
2. Any provider terms governing the archived generated responses.
3. Ownership and the intended license for the original study materials and
   newly prepared software.
4. Final publication citation, supplements, and any deposit version to cite.

Public availability of a benchmark does not by itself settle the licensing of
every adapted item. The manuscript, source benchmarks, and provider terms remain
the relevant sources for attribution and reuse conditions.

Stimuli may contain stereotypes or offensive benchmark language. They are
included for critical research/teaching analysis, not endorsement.

## Optional API access

Reproducing the archive requires no API credentials. The optional
[collector](../01_collection/README.md) has blank endpoints by default and reads
credentials from environment variables. Configure it only if you intend to
collect new responses, and keep credentials out of source files and shared
collection outputs.
